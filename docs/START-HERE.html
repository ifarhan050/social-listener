Social Listener

An assistant for Claude Cowork that finds what people are saying, on Facebook, news, YouTube, Reddit and RSS: complaints, scams, people looking for your services, competitors, or any topic. Version __VERSION__.

1Paste one message into Claude Cowork

Open a Cowork chat in the Claude app and paste this (change the last line to what you want to find):

Install Social Listener for me by following https://github.com/__SOCIAL_LISTENER_REPO__/blob/main/INSTALL.md
I agree to install it on this computer.
I want to find: complaints and scams about [my brand].

2Click accept

Claude shows a Social Listener plugin card. Click accept. Claude then sets up everything else by itself, including Node.js if needed, without admin rights, and runs your first search.

If Claude asks you to open a new chat, do that and type /setup.

3Facebook (optional)

If you want Facebook, Claude opens a Chrome window: log in once, then close the window. The login is kept.

No Cowork chat handy?

Double-click Install on Windows.cmd or, on a Mac, right-click Install on Mac.command → Open. Then add the plugin in Claude → Customize → Plugins → Add marketplace → https://github.com/__SOCIAL_LISTENER_REPO__.

4Things you can ask

Find 20 negative posts about [your brand] from last month
Find 10 people asking for a [home tutor] in [Lahore] this week
Find posts about [topic] in this Facebook group: [link]
Export my last search as a CSV
Write a report of what the agent found this week
Is everything working?

Type /start any time to see more ideas, tailored to what you set up.

Good to know

  • It only reads. It never likes, comments, joins groups or posts.
  • It only works when you ask. Nothing runs in the background.
  • Your results stay on your computer: a report (.md) and a spreadsheet (.csv) in your Cowork folder.
  • Facebook is read slowly, like a person, within daily limits. Automated reading is against Facebook's terms and can lead to a checkpoint, so a secondary account is safer.
  • Updating: say "update the agent" in Claude, or run the installer again. Your results and login are kept.
  • Uninstalling: double-click Uninstall on Windows.cmd / Uninstall on Mac.command. On Windows you can also use Start menu → Social Listener → Uninstall.
