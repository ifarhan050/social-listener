Facebook account

Reading Facebook automatically is against Facebook's terms and can lead to a checkpoint or restriction. The agent only reads, slowly and like a person, within daily limits — but the risk is not zero. A secondary account is safer.

Clicking Log in to Facebook opens a normal Chrome window. Log in there (including any code Facebook asks for), then close that window. You only do this once — the login is kept.
